# Epistemic Status

UAF must not become unfalsifiable.  
This file defines claim layers.

---

## Layer 0 — Established mathematics

Examples:

- KL divergence,
- Shannon entropy,
- Bayesian inference,
- variational free energy,
- active inference formalism,
- persistent homology,
- information geometry.

Status: established.

---

## Layer 1 — UAF core synthesis

Examples:

- stable systems can be modeled as prediction-error minimizers;
- hierarchy can be described as priors downward and errors upward;
- theory quality can be measured by predictive gain.

Status: research synthesis.

---

## Layer 2 — Cross-domain interpretations

Examples:

- language as collective free-energy minimization;
- science as collective active inference;
- economics as risk/uncertainty minimization.

Status: plausible, domain-dependent.

---

## Layer 3 — Physics reinterpretations

Examples:

- wavefunction as belief state;
- measurement as Bayesian update;
- spin as topology of prediction manifolds.

Status: interpretive, partially grounded in existing formalism.

---

## Layer 4 — Cosmological hypotheses

Examples:

- Big Bang as \(L_{-1}\to L_0\);
- CMB anomalies as traces of pre-temporal structure;
- dark sector as spacetime prediction architecture.

Status: speculative.

---

## Layer 5 — Metaphysical / theological extensions

Examples:

- Ω as ultimate attractor;
- religion as alignment practice.

Status: optional metaphysics, not empirical core.

---

## Criticism protocol

Every criticism should specify:

1. Which layer it attacks.
2. Which formula or mapping fails.
3. Whether failure is conceptual, mathematical, empirical, or rhetorical.
4. Whether the failure damages the core or only an extension.

---

## Rejection rule

If UAF does not improve predictive compression in a domain:

\[
\mathrm{NPG}_{UAF} \le 0
\]

then UAF should be rejected or revised in that domain.
